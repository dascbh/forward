# fde-build

An agent command, not a shell executable or a new engine.

Start from the requested outcome and constraints. Inspect code, history, backlog and foundations even for a new feature. Record baseline and evidence gaps. Augment discovery with research/benchmarks, falsifiable hypotheses and internal criticism.

Then follow `.fde/spec/product-pipeline.md`, shared with `fde-inspect`
and `fde-design-system`: stages, owners, criteria, provenance.
